# M3 日历连接与直接预约

打开 [.cn 管理后台](https://book-my-time-patrick.cn/#/admin)，进入「日历连接」。iCloud 和工作日历是两个独立来源。即使 Apple 日历同时显示两个账户，iCloud 连接仍只同步选中的私人日历。

## 私人 iCloud

1. 在 [Apple 账户](https://account.apple.com/) 打开「登录和安全」→「App 专用密码」，为本预约站生成一份专用密码。
2. 在本站后台的「私人 iCloud」填写 Apple 账户邮箱和该专用密码，点击「查找日历」。
3. 选择要参与忙闲计算的私人日历，点击「保存并同步」。看到「已同步」后，可以点「立即同步」再次验证。

站点使用 CalDAV 请求忙闲报告。专用密码加密保存，仅用于访问 Apple。连接前需要确认所选日历能返回忙闲报告；若 Apple 拒绝该请求，后台会显示原因，直接预约保持关闭。撤销授权时，可在本站断开连接，也可在 Apple 账户撤销这份专用密码。 [Apple App 专用密码说明](https://support.apple.com/zh-cn/102654)

## 工作 Outlook

Microsoft 365 与自建 Exchange 使用不同的接法。先确认单位账号的实际部署以及第三方日历读取政策。

### Microsoft 365 国际版或世纪互联

1. 在本单位对应区域的 Microsoft Entra 注册单租户应用，平台选择「Web」，填入后台给出的重定向 URI。
2. 为 Microsoft Graph 添加委托权限 `Calendars.ReadBasic`，按单位策略完成同意。在「证书和密码」生成客户端机密，复制它的**值**。
3. 在本站「工作 Outlook」选对应区域，填写租户 ID、应用 ID 和机密值，点击「去 Microsoft 授权」。
4. 授权返回本站后，选择实际工作的日历并点「保存并同步」。后续由服务器尝试刷新，不依赖手机和 Mac 开机。客户端机密过期后需重新授权。

[注册 Microsoft 应用](https://learn.microsoft.com/zh-cn/entra/identity-platform/quickstart-register-app) · [世纪互联与国际版地址](https://learn.microsoft.com/zh-cn/graph/deployments)

### 自建 Exchange

优先向单位 IT 核对对外 EWS 地址、允许的认证方式、是否批准站点服务器读取本人忙闲。EWS 的 `GetUserAvailability` 可只返回合并后的忙闲状态。邮箱后缀与 Apple 日历同步状态不足以确认这些条件。IT 未确认前，工作来源保持待连接。若单位仅开放内网，可请 IT 评估由单位服务器传出最小忙闲区间的方式。 [EWS 忙闲接口](https://learn.microsoft.com/en-us/exchange/client-developer/web-service-reference/getuseravailability-operation) · [EWS 认证方式](https://learn.microsoft.com/en-us/exchange/client-developer/exchange-web-services/authentication-and-ews-in-exchange)

## 开放与验收

1. 确认两个来源都显示「已同步」。后台每 5 分钟尝试同步，快照超过 10 分钟或读取失败会暂停真实忙闲显示和直接预约。人工邮件申请可继续使用。
2. 在「邮箱设置」配置发件服务和已验证的主送达邮箱。先发送测试日历附件，确认手机或电脑能收到。
3. 在「日历连接」点击「允许直接预约」。进入「邀请链接」，只为需要的邀请同时勾选「预约日历」和「直接预约」。旧邀请不会因上线自动启用。
4. 用「预览」查看周历、日视图、城市条及忙闲样式。按链接勾选「把已占用显示为未开放」可隐藏占用标记。
5. 用专用测试邀请验证真实预约。确认双方各收到一份确认附件，后台显示一条已确认记录。若外部日历在两次同步之间改变，站点会在下次同步后反映；站内重叠预约在提交时检查。

站点只保留来源状态和合并的忙碌时间区间，不把标题、参与人、地点和备注保存到忙闲缓存。Apple 专用密码、Microsoft 机密与授权令牌只填写在管理后台。
