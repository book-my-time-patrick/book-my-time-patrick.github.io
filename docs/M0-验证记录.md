## Argon2id 预检

使用 `@noble/hashes` JavaScript 实现，参数为 19 MiB 内存、2 次迭代、并行度 1、32 字节输出。输入均为公开虚构字符串。

5 次本机 Node CPU 样本为 186.751、134.426、131.127、139.699、137.351 ms，中位数 **137.351 ms**。完整本机结果在忽略提交的 `.local/auth-probe.json`。

相同计算在本地 workerd 的隔离探针中执行成功。**截至 11 月 4 日，Cloudflare 线上 CPU 尚未验证**，不能把本地成功当作满足免费版额度。JavaScript 实现的耗时也不能代表所有优化实现。Workers 免费版标称 HTTP CPU 预算为 10 ms，因此当时判断本次实现存在明显超限风险，安全登录的免费方案暂未通过。

11 月 5 日已补做线上计算测试。两种 Argon2id 实现均反复超限，用户选择通行密钥 + TOTP；P-256 验签、TOTP 和组合核心测试各 12/12 通过。密码学核心方向已选定，完整 WebAuthn、会话、设备管理及免费额度下的完整登录验收留在 M1。逐次云端 CPU 毫秒数仍未取得，详见线上验证记录。

[Workers 限制](https://developers.cloudflare.com/workers/platform/limits/) · [OWASP 密码存储建议](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)
