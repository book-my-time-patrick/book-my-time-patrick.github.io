## Argon2id 预检

使用 `@noble/hashes` JavaScript 实现，参数为 19 MiB 内存、2 次迭代、并行度 1、32 字节输出。输入均为公开虚构字符串。

5 次本机 Node CPU 样本为 186.751、134.426、131.127、139.699、137.351 ms，中位数 **137.351 ms**。完整本机结果在忽略提交的 `.local/auth-probe.json`。

相同计算在本地 workerd 的隔离探针中执行成功。**Cloudflare 线上 CPU 未验证**，不能把本地成功当作满足免费版额度。JavaScript 实现的耗时也不能代表所有优化实现。Workers 免费版标称 HTTP CPU 预算为 10 ms，因此本次实现存在明显超限风险，安全登录的免费方案暂未通过。

M1 前需要验证适合 Workers 的实现或决定兼容 Argon2id 的后端运行方式。若涉及改变登录方式或增加费用，需要先明确相应取舍。
