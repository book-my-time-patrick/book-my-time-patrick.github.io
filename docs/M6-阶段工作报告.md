## 操作手册

### Node + SQLite

先确认数据库所在主机和实际 DATABASE_PATH。本机 Node 默认使用 .local/app.sqlite，容器内为 /app/data/site.sqlite。脚本要求源库可读、目标目录已存在且目标文件名未使用。

```bash
mkdir -m 700 -p backups
node scripts/backup-sqlite.mjs .local/app.sqlite "backups/booking-$(date -u +%Y%m%dT%H%M%SZ).sqlite"
```

用同一脚本创建独立的恢复副本，并核对输出的最后迁移。

```bash
mkdir -m 700 -p .local/restore-check
node scripts/backup-sqlite.mjs backups/booking-YYYYMMDDTHHMMSSZ.sqlite .local/restore-check/app.sqlite
```

将数据库备份和匹配的 DATA_ENCRYPTION_KEY 分开存入受控位置。备份含访客信息及可恢复的会话状态。通行密钥验收需使用注册时的站点来源和 RP ID。演练使用合成数据，或在隔离环境关闭出站发信与日历同步。验证迁移、登录、邀请、预约和邮件配置后，按计划停止旧实例并切换数据库路径，确保只有一套实例接受写入。回退到历史时点后，核对备份以来已撤销的会话、邀请及需要补录的预约。

### Cloudflare 正式 D1

恢复 Cloudflare 连接后，从项目根目录查询账号、迁移列表、正式数据库书签并导出 SQL。Cloudflare Free 的 Time Travel 窗口为 7 天。SQL 导出期间可能暂时阻塞查询，安排在低流量时段。

```bash
npx wrangler whoami
npx wrangler d1 migrations list DB --remote --config .local/wrangler.production.jsonc
mkdir -m 700 -p backups
umask 077
m6_backup="backups/d1-before-m6-$(date -u +%Y%m%dT%H%M%SZ)"
npx wrangler d1 time-travel info DB --config .local/wrangler.production.jsonc > "$m6_backup.bookmark.txt"
npx wrangler d1 export DB --remote --config .local/wrangler.production.jsonc --output "$m6_backup.sql"
```

逐条检查命令成功及输出非空。使用空的隔离数据库验证导入。若导出按表交错排列建表与写入，先用保留完整 SQL 语句边界的工具建立所有表，再导入数据与索引。正式 Time Travel 恢复会回退当前数据库，执行前核对目标书签、停写、撤销和数据补录方案。

完成预检和恢复演练后，按 README 应用 0009 和 0010，再发布 Worker。正式复查首页、同源 API、无效邀请、管理员登录、规则保存及审计。GitHub Pages 备用入口沿用仓库发布流程。
