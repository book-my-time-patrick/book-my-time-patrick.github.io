## 应保留的产品决定

- 预约页沿用 Mac 日历风格，桌面周视图和手机日视图使用连续网格。占用、选中和开放局有色块。桌面每半小时 21px，手机日视图每半小时有 44px 点选区。
- 城市由管理员填写默认值或按日期覆盖，显示在「全天」行。邀请需要同时授予「预约日历」和「城市行程」才能看到城市。
- 目前普通预约为周一至周五 09:00–21:00，最远 30 天，30 分钟起点，可选 30/60/90/120 分钟。普通申请由邀请人确认。周末可发布开放局，开放局可临时安排。
- 开放局六种预置类型是 Coffee chat、Lunch、Dinner、Bar talk、Airport chat、Video call，默认 60 分钟、1 人。待审批报名在确认时检查名额。已发布的开放局占用普通预约时段。
- 私人和工作日历分别只读，外部事件只处理忙闲区间。工作日历优先由服务器同步，因 Mac 经常出差随身携带。忙闲同步每 5 分钟尝试一次，快照有效期 10 分钟，过期后直接预约暂停。

## 验证记录

- M5 的隔离 Workers/D1 测试应用了 9 个迁移，覆盖旧邀请从 0008 升级后继承新规则、后台保存全局及逐邀请覆盖、预览权限、请求校验和已有预约行为。Chromium 使用正式构建和本地 API，确认后台保存、邀请创建与覆盖预览、15 分钟网格、375px 布局和提交入库。邮件由模拟服务接收。
- 正式 D1 只读迁移预检失败。Wrangler 登录已过期，无法连接 Cloudflare 刷新。此轮未向正式 D1 应用 0009，也未发布 Worker 或 GitHub Pages。

- 发布基线的 TypeScript 检查和 62 项自动测试通过。隔离 Workers 与 D1 执行 8 个迁移、通过 32 项检查，覆盖同一名额并发、重复提交、指定邀请和冲突时段。
- Chrome 使用合成数据验证桌面和窄屏、切周、点选、访客报名、预览及后台批量发布。线上复查确认主站返回新版前端，后台和开放局报名接口的门禁按预期工作。部分请求出现连接超时，经重试取得预期响应。
- 邮件和日历授权测试使用合成数据。真实账户授权、收件和大陆网络结果按各自的验收记录更新。 [M0 网络记录](M0-线上验证记录.md) · [M1 登录](M1-使用与验证.md) · [M2 邮箱](M2-邮箱与预约申请.md) · [M3 日历连接](M3-日历连接.md)
