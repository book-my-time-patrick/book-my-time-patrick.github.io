# 日历视觉方案（请挑一个）

> 更新：B、C 两套已经落地为网站的可切换外观（紧凑 = C，苹果 = B），并加入了拖动选择，见 `docs/日历拖选与外观.md`。下面保留为设计记录。

三个方案都是**可直接双击打开的静态原型**（单个 HTML，无构建、无外链字体、虚构数据），只演示视觉与交互手感，**没有改动网站任何代码**。你挑定后，我再把它落到 `web/src/invitation-booking.css` 和少量标记里，不动 JS 逻辑和 API。

| 文件 | 风格 | 参考 |
| --- | --- | --- |
| `方案A-暖纸质感.html` | 奶油底、圆角日列胶囊、斜纹=占用、绿块=可约、黑色选中标签、棕色“现在”线；右侧固定预约面板 | 参考样式1 |
| `方案B-苹果日历.html` | 苹果日历：周号+日期头、“全天”行放城市、事件块=半透明底色+左色条、细线网格；浅色/深色一键切换 | 参考样式2 |
| `方案C-高密度融合.html` | **推荐**。A 的斜纹/绿块 + B 的“全天”行与细线网格，沿用站点现有蓝色主色；整体最紧凑 | 两者融合 |

打开方式：直接用浏览器打开文件。B、C 支持 `?theme=dark` 看深色（页面里 B 有 ◐ 按钮）。C 在窄屏下是底部抽屉，可加 `?sheet=open` 直接展开。

`截图/` 里有各方案的 1440 宽截图，以及真实 390px 宽下的手机对照：`手机390并排-ABC.png`（三案并排）、`手机390-C抽屉.png`（C 的抽屉折叠/展开，含深色）。原型只画了周视图，日视图、翻周按钮没有接逻辑；示例数据固定为 2026-11-23 这一周，“现在”固定在周一 11:00。

## 对比

| | A 暖纸质感 | B 苹果日历 | C 高密度融合 |
| --- | --- | --- | --- |
| 30 分钟槽高 | 30px（宽松，贴近参考图） | 22px | **16px**（现状 21px） |
| 一屏能看到 | 日历约 2/3 天 | 约 12 小时需轻滚 | **整周 09–21 点 + 完整表单** |
| 正文字号 | 12–14px | 11–14px | 11–13px |
| 卡片内边距 | 22px | 16px | **10–12px**（现状 22–23px） |
| 空闲表现 | 绿块（可点） | 空白（悬停出“+”） | 绿块（可点） |
| 占用表现 | 斜纹 | 灰色“已占用”块 | 斜纹 |
| 深色模式 | 无 | 有 | 有 |
| 选时段后的表单 | 右侧固定面板 | 右侧“新建预约”分组列表 | 右侧紧凑面板；手机为底部抽屉（选中即出现） |
| 手机（≤640px） | 7 列紧凑日历，面板在下方 | 7 列紧凑日历，面板在下方 | 7 列紧凑日历 + 底部抽屉 |
| 落地改动量 | 中（样式较多） | 中（深色需整套变量） | **小**（以现有 class 为主，只换样式） |

### 我的建议：C，必要时借 A 或 B 的一处细节
- 你要“信息密度更高”，C 把槽高从 21px 压到 16px，整周一屏可见，且选完时间不用再滚到页面下方。
- C 沿用站点现有蓝色主色与系统字体，和后台、邀请页其余部分风格一致，改造风险最小。
- 如果你更喜欢 A 的温暖奶油色，可以做成“C 的结构 + A 的配色”；喜欢苹果的深色，可以做成“C 的结构 + B 的深色变量”。直接告诉我即可。

## 与现有代码的对应（保证只改样式、不改逻辑）

现有 JS 生成的 class 与 `data-*` 全部保留，视觉靠 CSS 变化实现：

| 现有 class / 状态 | 原型中的对应视觉 |
| --- | --- |
| `.booking-slot.available` / `.request`（可申请） | 绿块（A、C）；B 为空白+悬停提示 |
| `.booking-slot.busy`（已占用，`joins-before/after` 连成一块） | A、C：斜纹；B：灰色块 |
| `.booking-slot.unavailable` / `.expired` | 更淡的斜纹 / 平底 |
| `.booking-slot.selected` + `selection-first/last` | A：黑色标签+描边；B：蓝色实心块；C：蓝色实心块 |
| `.booking-open-slot--blue/plum/green/amber` | 半透明底 + 左色条 + 同色文字（B、C），A 为同色浅底 |
| `.booking-location-row` / `.booking-location-label` | “全天”行里的城市胶囊（A、B、C 都有，落实你在参考样式2上的批注） |
| `[aria-current='date']` | 今天的红色圆点日期（A 为棕色） |
| `.booking-range-chip`、“填写申请 ↓” | C/A/B 中取消：选中时间后右侧面板（手机为抽屉）直接带入 |
| 表单字段 `name/email/notes/duration/date/start` | 保持不变，只调整排布与尺寸 |

需要少量标记改动的地方（不涉及逻辑）：
- “现在”线与右侧面板需要在 `.booking-calendar-card` 外层加一个两栏容器；
- “全天”行已存在（城市行），只需样式；
- C 的手机抽屉需要给表单卡加一个可折叠头部。这一项会略微动到 `invitation-booking.ts` 的标记，我会单独标出，等你确认再做。

对比度：我用脚本逐项计算过主要的文字/底色组合，**均 ≥4.5:1（WCAG AA 正文标准）**。包括 A 与 C 的正文、次要文字、可约块文字、四种开放局文字、主按钮、深色模式，以及 B 的次要文字与主按钮（B 浅色原本只有 3.26:1 和 4.01:1，已把次要文字调为 `#6b6b70`、主色调为 `#0062cc`，现为 5.3:1 和 5.8:1）。深色模式下白字压亮蓝底也不达标（C 为 3.16:1，B 为 3.65:1），已改为“深色用更深的蓝做填充、亮蓝只用于深底上的文字”（C 填充 `#3568dd` 为 5.03:1，B 填充 `#0a6fe0` 为 4.81:1）。B 里“已占用”和开放局块的文字是页面运行时按比例混色得到的，尚未逐一核对，落地时会再测一遍。占用斜纹属装饰，占用状态同时有图例文字。
